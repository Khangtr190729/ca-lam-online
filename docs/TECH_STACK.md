# Ca Làm Online — Tech Stack

## 1. Frontend Web (Admin / Manager)

| Công nghệ | Mục đích sử dụng |
|---|---|
| React.js | Xây dựng giao diện quản lý và phân ca. |
| Vite | Khởi tạo môi trường phát triển và build ứng dụng. |
| JavaScript | Ngôn ngữ lập trình frontend. |
| React Router | Điều hướng trang và quản lý routes theo role. |
| Tailwind CSS | Thiết kế giao diện và responsive. |
| Lucide React | Cung cấp icon cho giao diện. |
| FullCalendar | Hiển thị lịch làm việc và lịch phân ca. |
| Axios | Gửi request đến Backend API. |

## 2. Mobile App (Employee)

| Công nghệ | Mục đích sử dụng |
|---|---|
| React Native | Xây dựng ứng dụng di động cho nhân viên. |
| Expo | Hỗ trợ phát triển và chạy ứng dụng React Native. |
| React Navigation | Điều hướng giữa các màn hình. |
| Axios | Gọi Backend API. |
| Expo SecureStore | Lưu trữ thông tin xác thực an toàn trên thiết bị. |
| Expo Notifications | Hỗ trợ push notification ở giai đoạn sau. |

## 3. Backend

| Công nghệ | Mục đích sử dụng |
|---|---|
| Node.js | Môi trường chạy JavaScript phía server. |
| Express.js | Xây dựng REST API và xử lý request. |
| MongoDB Atlas | Lưu trữ dữ liệu ứng dụng trên cloud. |
| Mongoose | Định nghĩa schema và truy vấn MongoDB. |
| JWT | Xác thực người dùng bằng token. |
| bcrypt | Băm mật khẩu trước khi lưu vào database. |
| Zod | Kiểm tra và xác thực dữ liệu đầu vào. |

## 4. Tools

| Công cụ | Mục đích sử dụng |
|---|---|
| GitHub | Quản lý source code và lịch sử thay đổi. |
| Postman | Gửi request và kiểm thử REST API. |
| Thunder Client | Kiểm thử REST API trực tiếp trong VS Code. |
